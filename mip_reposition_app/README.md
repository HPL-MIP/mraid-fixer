# MIP Reposition Studio

A local React web app for repositioning content in React source-project ZIPs. The included `sample.zip` is the reference: a Vite/React TypeScript project with MIP3/MIP4 variants and state-driven scan scenes.

## Start

Install Node.js 20 or newer, then double-click `start_app.bat`, or run these commands from this folder:

```
npm.cmd install
npm.cmd start
```

Open http://localhost:3100. The server listens only on the local computer. Set `PORT` to change the port. Uploaded ZIPs and previews stay in server memory; restarting clears them. Only the most recent three projects are retained.

## React application

The editor mounts with ReactDOM `createRoot` in `src/main.jsx`. `src/App.jsx` contains the toolbar, scene/content sidebar, preview canvas, and position inspector. `src/useEditor.js` manages React state, undo/redo, preview messages, import, and export. The existing Node API and ZIP engine remain in `server.cjs` and `engine.cjs`.

`npm.cmd start` builds the React frontend with esbuild and starts the server. `npm.cmd run build` produces `dist/`. `npm.cmd run dev` uses Node watch mode to restart and rebuild when source files change (refresh the browser afterward). No additional dependencies are required.

## Edit and export

1. Import a React source ZIP, drop it onto the canvas, or select **Explore sample.zip**.
2. Select the creative variant and scene. For the reference project, Initial, Scanning, Scan result and End card pin its existing React state for preview only.
3. Pick a content item or click it in the preview. Drag it, edit X/Y, or use arrow keys (Shift moves 10 pixels). Coordinates are offsets in local CSS pixels from the original layout. Landscape and portrait previews share these offsets.
4. Changes apply to the selected variant across scenes. Undo, redo and reset are available. Interact mode allows normal app gestures; the reference scene flags remain pinned.
5. Export the ZIP. Every original entry is retained; unrelated file contents remain byte-identical. Only JSX files containing edited elements and the project's CSS change. The exported archive is recompressed, so its ZIP bytes and compressed sizes differ.
6. Unzip the export and run the original project's install and build commands to regenerate its production HTML. Existing build artifacts inside the archive are preserved; they are not rebuilt by this editor.

Re-importing an exported ZIP restores saved offsets. Export adds stable `data-mip-node` attributes only to edited native JSX elements and appends scoped CSS `translate` rules plus layout metadata to the existing stylesheet. CSS `translate` preserves authored `transform` rules. Reset removes the layout rules; added data attributes are harmless and retained on re-import.

## Supported projects and limits

- React/ReactDOM local-source projects with `src/main` or `src/index` in TSX, JSX or JS; TypeScript source modules are supported. Both ZIP root projects and a containing folder work.
- Local relative imports, `@/` source aliases, and the sample's `@active-variant` / `@active-experience` aliases. React/ReactDOM use the editor's installed runtime.
- Scene presets specifically recognize the reference `src/experiences/MipExperience.tsx`. Other projects get a live application view; Interact mode can navigate their normal scenes. Arbitrary Vite plugins, additional npm packages, dynamic asset URLs, custom aliases and server backends are not automatically executed or supported. Compilation errors are shown in the editor.
- Editable contents are rendered native DOM elements instrumented from source JSX. Canvas-drawn objects, pseudo-elements and content generated by third-party libraries are not separate editable items.
- Offsets are variant-specific, shared across viewport sizes and scenes, and do not rewrite React logic or create responsive breakpoints. Moving a parent also moves its children. Rotation/skew transforms can affect dragging; numeric coordinates remain available.
- The preview runs in a scripts-only sandbox with network access blocked. Uploaded build scripts, Vite configuration and dependency lifecycle scripts are never executed. External services, externally hosted assets, navigation and network-dependent behavior are unavailable in preview.
- Maximum upload: 160 MB; expanded archive content: 512 MB. Large audio/video archives can require substantial memory. Projects should be trusted local source archives.
- `npm.cmd test` verifies the reference scene builds, archive preservation, repeat exports, coordinate validation, and wrapped projects.
